# Сайт цветочного магазина «Цвети»

Одностраничный сайт: каталог 15 букетов, форма заказа, онлайн-оплата (Точка Банк), кнопки связи, админка.
Работает на обычном хостинге с **PHP 8.0+** (Beget, Timeweb, Reg.ru, и т. п.). База данных не нужна — всё хранится в файлах.

## Что где лежит

| Путь | Назначение |
|---|---|
| `index.html`, `assets/` | Сайт (дизайн, стили, скрипты) |
| `data/products.json` | Каталог (меняется через админку) |
| `data/settings.json` | Телефон, WhatsApp, Telegram, Max, часы работы (через админку) |
| `uploads/` | Фото букетов (сейчас — иллюстрации-заглушки) |
| `api/order.php` | Приём заказа, создание ссылки на оплату, уведомление в Telegram |
| `admin/` | Админка: `https://ваш-сайт.ru/admin/` |
| `private/config.php` | **Ключи**: Точка, Telegram, адрес сайта. Папка закрыта от браузера |
| `private/orders/` | Все заказы (создаётся автоматически) |
| `thanks.html` | Страница после оплаты |
| `tools/` | Служебный скрипт заглушек — на хостинг загружать не нужно |

## Запуск на хостинге (по шагам)

1. Купите/привяжите домен и тариф с PHP 8+. Включите бесплатный SSL (https) в панели хостинга.
2. Загрузите **всё содержимое папки проекта** (кроме `tools/` и `README.md`) в корневую папку сайта (`public_html` / `www`) по FTP или через файловый менеджер.
3. Убедитесь, что у папок `data/`, `uploads/`, `private/` есть права на запись (обычно 755, при проблемах — 775).
4. Откройте `https://ваш-сайт.ru/admin/` — **сразу задайте пароль** (первый, кто откроет страницу, его задаёт).
5. В админке → «Контакты» укажите свои телефон, WhatsApp, Telegram, Max.
6. Заполните `private/config.php` (см. ниже).
7. Раскомментируйте перенаправление на https в `.htaccess` (внизу файла).
8. Сделайте тестовый заказ.

## Онлайн-оплата (Точка Банк)

Сайт создаёт платёжную ссылку через интернет-эквайринг Точки (оплата картой и СБП на странице банка; данные карт на сайт не попадают).

1. В Точке подключите **интернет-эквайринг** к вашему расчётному счёту.
2. В интернет-банке: «Интеграции и API» → создайте токен с правами на эквайринг.
3. В `private/config.php` впишите:
   - `tochka_token` — токен;
   - `tochka_customer_code` — код клиента (виден в разделе API / в данных счёта);
   - `site_url` — адрес сайта, например `https://cveti-rostov.ru`;
   - `tochka_merchant_id` — только если у вас несколько торговых точек.
4. Сделайте тестовый заказ на небольшую сумму и проверьте, что открылась страница оплаты.

> Интеграция написана по публичной документации API Точки; для вашего аккаунта её нужно один раз проверить боевым тестовым платежом. Если ссылка не создалась, заказ всё равно сохраняется и приходит вам, клиент видит «пришлём ссылку на оплату», а в Telegram-уведомлении появится пометка. Если в личном кабинете Точки схема другая — напишите, подстроим.

Оплату видно в личном кабинете Точки. В админке → «Заказы» есть кнопка «Проверить оплату» (запрашивает статус в банке).

## Уведомления в Telegram (рекомендуется)

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Напишите своему боту любое сообщение. Свой chat_id узнайте у [@userinfobot](https://t.me/userinfobot).
3. Впишите `telegram_bot_token` и `telegram_chat_id` в `private/config.php`.

Каждый новый заказ придёт вам в Telegram со всеми данными (адрес, получатель, открытка, оплата).

## Как менять товары (для владельца)

Откройте `https://ваш-сайт.ru/admin/` → вкладка **«Товары»**:

- **Фото** — «Заменить фото», выберите файл (JPG/PNG/WEBP, лучше вертикальное 4:5). Сайт сам уменьшит большие фото.
- **Название, цена, состав** — правьте прямо в полях.
- **↑ ↓** — порядок на сайте. **«Показывать на сайте»** — скрыть без удаления.
- **«+ Добавить товар»** — новая карточка. **«Удалить»** — убрать.
- В конце обязательно нажмите **«Сохранить»** — изменения сразу появятся на сайте.

Вкладка «Заказы» — все заказы, статусы. «Контакты» — телефон и мессенджеры. «Пароль» — смена пароля.

## Что стоит заменить перед запуском

- Цены, названия и составы в `data/products.json` — **примерные**, поправьте в админке.
- Иллюстрации в `uploads/` — заглушки: загрузите настоящие фото букетов.
- Контакты в `data/settings.json` — **тестовые** (+7 900 000-00-00).
- **Оферта и политика конфиденциальности** (`offer.html`, `privacy.html`): откройте оба файла и заполните места, подсвеченные жёлтым (`[ИП ...]`, ИНН, ОГРНИП, адрес, e-mail, телефон, дата, расчётный счёт, условия стоимости доставки). Подсвечены тегом `<mark>` — после заполнения уберите теги `<mark>` и `</mark>` (или оставьте, но подсветка будет видна клиентам). Тексты — типовой шаблон; перед запуском их стоит показать юристу или бухгалтеру.

## Безопасность

- Цена заказа берётся с сервера, а не из формы — подменить её нельзя.
- Вход в админку защищён паролем, защитой от подбора и CSRF-токеном; загружаются только JPG/PNG/WEBP, скрипты в `uploads/` запрещены.
- `private/` закрыта через `.htaccess` (Apache). Если хостинг работает на чистом nginx, попросите поддержку закрыть папку `private/` от внешнего доступа.
