# Сайт цветочного магазина «Цвети»

Одностраничный сайт: каталог 15 букетов, форма заказа, онлайн-оплата (Точка Банк), кнопки связи, админка.
Работает на обычном хостинге с **PHP 8.0+** (Beget, Timeweb, Reg.ru, и т. п.). База данных не нужна — всё хранится в файлах.

## Что где лежит

| Путь | Назначение |
|---|---|
| `index.html`, `assets/` | Сайт (дизайн, стили, скрипты) |
| `data/products.json` | Каталог (меняется через админку) |
| `data/settings.json` | Телефон, WhatsApp, Telegram, Max, часы работы (через админку) |
| `uploads/` | Фото букетов (сейчас — иллюстрации-заглушки) |
| `api/order.php` | Приём заказа, создание ссылки на оплату, уведомление в Telegram |
| `admin/` | Админка: `https://ваш-сайт.ru/admin/` |
| `private/config.php` | **Ключи**: Точка, Telegram, адрес сайта. Папка закрыта от браузера |
| `private/orders/` | Все заказы (создаётся автоматически) |
| `thanks.html` | Страница после оплаты |
| `tools/` | Служебный скрипт заглушек — на хостинг загружать не нужно |

## Запуск на хостинге (по шагам)

1. Купите/привяжите домен и тариф с PHP 8+. Включите бесплатный SSL (https) в панели хостинга.
2. Загрузите **всё содержимое папки проекта** (кроме `tools/` и `README.md`) в корневую папку сайта (`public_html` / `www`) по FTP или через файловый менеджер.
3. Убедитесь, что у папок `data/`, `uploads/`, `private/` есть права на запись (обычно 755, при проблемах — 775).
4. Откройте `https://ваш-сайт.ru/admin/` — **сразу задайте пароль** (первый, кто откроет страницу, его задаёт).
5. В админке → «Контакты» укажите свои телефон, WhatsApp, Telegram, Max.
6. Заполните `private/config.php` (см. ниже).
7. Раскомментируйте перенаправление на https в `.htaccess` (внизу файла).
8. Сделайте тестовый заказ.
